# 初中数学教材智能语音化仿真系统

这是一个面向视障群体的初中数学教材智能语音化仿真系统原型，当前界面分为三部分：

- 首页：上传教材 PDF
- 列表页：展示已加载的教材书籍列表
- 展示页：按页阅读教材，并支持版面框点击点读、上一页/下一页、重复播放、语速调节和导出音频

## 运行方式

```bash
python app.py
```

然后访问：

- http://127.0.0.1:5000
- http://127.0.0.1:5000/books

## 说明

- 系统默认会加载工作区内已处理好的教材数据作为示例。
- 展示页会根据版面识别结果在页面上显示不同的可点击区域。
- 语音合成依赖系统语音引擎，Windows 下通常可直接使用系统 TTS。
- 导出音频会生成 WAV 文件，保存在 static/audio_exports 目录下。
